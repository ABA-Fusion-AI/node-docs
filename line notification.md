# LINE Notification

> **Category:** Communications | **Type:** Action Node

Connect to the LINE Messaging API to automate the delivery of rich push messages. You can send text broadcasts, images, and native animated characters (like Moon, Sally, and Brown) to your target users effortlessly.

<!-- /SECTION: header -->

---

<!-- SECTION: overview -->
## Overview

The **LINE Notification** action node gives you programmatic access to the LINE Push Messaging API. It handles formatting nested message arrays out-of-the-box and includes native validation for common pitfalls like unsecure image links or missing fallback thumbnails.

### Key Features

- **Rich Media Capable:** Sends basic text, full-sized images, and pre-packaged LINE character stickers simultaneously in a single push.
- **Native Security Validation:** Automatically double-checks that your image payloads are appropriately hosted over HTTPS with raw file extensions (e.g., `.png`, `.jpg`).
- **Silent Mode:** Optional flags to disable push notification alerts on the recipient's mobile device for non-urgent deliveries.

### Use Cases

- Send a fast SMS-alternative alert directly to an administrator's internal LINE account when a server goes down
- Automatically thank e-commerce customers via LINE with an attached "Thank You - Warm Thanks" sticker when an order completes
- Distribute daily image reports (like weather graphs or metric snapshots) strictly formatted via HTTPS endpoints

## Configuration

### Connection Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `channelAccessToken` | `string` | ✅ Yes | — | Your LINE Channel Access Token for API authentication |

### Common Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `resource` | `enum` | ✅ Yes | `Notification` | Determines the overarching resource block |
| `operation` | `enum` | ✅ Yes | `Send`| Operation to perform |

### Message Construction

You must provide **at least one** of the following payloads: `Message`, an `Image Full Size` (coupled with a thumbnail), or a `Sticker`. You can absolutely provide all three at once!

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `to` | `string` | ✅ Yes | The LINE User ID to receive the notification |
| `message` | `string` | ❌ No | Text message to send |
| `notificationDisabled` | `boolean`| ❌ No | Check this to send the message without alerting the receiver's phone |
| `imageFullSize` | `string` | ❌ No | Direct HTTPS URL to a full-size image (`.jpg`, `.png`, etc.) |
| `imageThumbnail` | `string` | ❌ No | Direct HTTPS URL to a thumbnail image (required if Full Size is used)|
| `sticker` | `enum` | ❌ No | A selection of official LINE stickers (e.g. `Brown & Cony - Party Time`) |

## Examples

### Example: Send a Basic Text and Sticker Combo

Push a welcoming text message accompanied by an animated 'Sally - Big Smile' sticker to a new user.

**Configuration:**
```json
{
  "channelAccessToken": "your_access_token_here",
  "to": "U4af4980629...",
  "message": "Welcome to our premium group!",
  "sticker": "Sally - Big Smile"
}
```

**Output:**
```json
{
  "operation": "Send",
  "success": true,
  "data": {
    "to": "U4af4980629...",
    "messageCount": 2,
    "types": ["text", "sticker"],
    "sticker": "Sally - Big Smile"
  }
}
```

---

### Example: Send a Silent Image

Send an image generated by a previous workflow step silently to a user's chat, skipping the mobile push alert.

**Configuration:**
```json
{
  "channelAccessToken": "your_access_token_here",
  "to": "U4af4980629...",
  "notificationDisabled": true,
  "imageFullSize": "https://example.com/daily-chart.png",
  "imageThumbnail": "https://example.com/daily-chart-thumb.png"
}
```

**Output:**
```json
{
  "operation": "Send",
  "success": true,
  "data": {
    "to": "U4af4980629...",
    "messageCount": 1,
    "types": ["image"],
    "sticker": null
  }
}
```

## Troubleshooting

### Common Issues

#### `Invalid credentials` error

**Cause:** The provided Channel Access Token is incorrect, expired, or missing.

**Solution:** Verify your `channelAccessToken` inside your LINE Developer Console and ensure your token permissions allow Push messaging.

#### `Image Full Size must use HTTPS` error

**Cause:** HTTP protocols are strictly banned by the LINE Platform for security reasons.

**Solution:** Ensure your `imageFullSize` and `imageThumbnail` hosted URLs begin with `https://`.

#### `Must be a direct image URL` error

**Cause:** The image string provided was likely a standard webpage (e.g. an Imgur or Wikipedia HTML page view) rather than a raw byte payload.

**Solution:** Extract the direct element link containing the raw extension (`.jpg`, `.png`, `.webp`).

#### `Image Thumbnail URL is required` error

**Cause:** You mapped an `imageFullSize` value but forgot the thumbnail. LINE requires both to properly render image previews in-app.

**Solution:** Provide an accompanying properly formatted HTTPS Thumbnail URL.
